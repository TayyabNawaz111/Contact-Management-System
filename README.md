Contact Management System
This is a simple Java-based Contact Management System built using Swing. The application allows you to manage your contacts by adding, editing, removing, and searching for them. It displays the contact details (Name, Phone, Email, Address) in a table and provides functionality to view all contacts.

Features
Add a new contact
Edit existing contact
Remove a contact
Search contacts by name
View all contacts
How to Run
Clone or download the repository.
Compile and run the ContactManagementSystem class.
The application will open with options to manage contacts.
Dependencies
Java 8 or higher
No additional libraries are required.
